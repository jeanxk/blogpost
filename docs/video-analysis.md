# 픽포스트 영상 분석

분석 대상: [사용자가 제공한 영상](https://www.youtube.com/watch?v=yBRngYn7h7w) — “블로그 포스팅 5분 컷? 사진만 넣으면 AI가 알아서 써주는 픽포스트 사용법”

영상은 약 20분 40초 분량으로, 화면 스토리보드 프레임을 약 10초 간격으로 처음부터 끝까지 확인하고 현재 공식 서비스 화면을 함께 대조했다. 화면의 작은 텍스트가 모두 판독되는 원문 자막 분석은 아니므로, 아래는 확인된 제품 흐름 중심의 분석이다.

## 관찰된 사용자 흐름

| 구간 | 관찰한 흐름 | 블로그포스트에 반영한 결정 |
| --- | --- | --- |
| 0:00–1:20 | 사진 기반 블로그 작성과 네이버 쇼핑/브랜드 커넥트 활용 맥락을 소개하고 서비스 진입·요금 화면을 보여준다. | 첫 화면에서 작성·수익화·정책을 별도 축으로 분리한다. |
| 1:20–4:20 | 상품/콘텐츠를 찾고 상품 상세·설명·추천 정보에 접근한다. | 상품 링크를 무작정 생성하지 않고, 출처와 채널을 입력받는 제휴 링크 레이어를 둔다. |
| 4:20–7:20 | 사진 선택 화면에서 여러 장을 고르고 글감/메모를 입력한다. | 사진 정렬, 다중 업로드, 500자 메모, 톤앤매너를 MVP 핵심 입력으로 둔다. |
| 7:20–10:30 | 생성된 한국어 글을 미리 보고 문단·이미지 배치를 확인한다. | 편집 가능한 제목·본문·이미지 순서와 생성 후 확인 상태를 제공한다. |
| 10:30–15:40 | 문서 편집 화면과 블로그 게시 준비 화면을 오가며 이미지와 본문을 다듬는다. | 내보내기/복사와 “검토 후 직접 발행”을 명시하고, 네이버 자동 대량 발행은 넣지 않는다. |
| 15:40–18:50 | 생성 글, 이미지, 상품/추천 정보가 함께 있는 최종 초안을 점검한다. | 정책 점검을 생성 결과 옆에 항상 보여주고, 확인 필요 사실을 별도로 남긴다. |
| 18:50–20:40 | 서비스 요금제와 작성 결과 화면으로 마무리한다. | 향후 과금은 포스트 수가 아니라 팀·채널·검수·분석 기능에 연결할 수 있게 구조화한다. |

## 픽포스트에서 확인한 가치

현재 공식 서비스도 “사진 + 짧은 메모 → 초안 미리보기 → 사용자 말투에 맞게 완성”의 4단계 흐름을 중심으로 설명한다. 음식점/상품 리뷰뿐 아니라 매장 홍보, 현장 기록, 인테리어·청소·수리 업종으로 확장할 수 있고, 사진 순서, 키워드 검색량, 장소/상품 정보, 말투·분량 설정을 보조한다. [PicPost 공식 사이트](https://picpo.app/)

## 복제하지 않고 업그레이드한 부분

1. **초안과 게시를 분리**: 생성물은 반드시 사람이 읽고 수정한다.
2. **수익화 링크를 문맥에 배치**: 링크를 많이 넣는 것이 아니라 상품/캠페인·관련 문단·표기 문구를 하나의 단위로 관리한다.
3. **정책을 결과물의 일부로 취급**: 네이버·공정위·쿠팡·AdSense 위험 신호를 원고와 함께 보여준다.
4. **근거 상태를 명시**: 사진과 메모로 확인할 수 없는 가격·위치·방문 경험은 `[확인 필요]`로 남긴다.
5. **채널별 수익의 성격을 구분**: Naver Brand Connect 캠페인, Naver Shopping Connect 판매 수익, Coupang 제휴 링크, 소유 사이트의 AdSense, Toss의 파트너십/미니앱을 한데 섞어 “무조건 수익”처럼 보이지 않게 한다.
